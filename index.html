Factorial Add-in

Install the hosted Excel add-in by uploading its manifest through Excel Online.

Install in Excel Online

  1. Download manifest.xml using the button above.
  2. Open Excel Online.
  3. Go to Insert → Add-ins → Upload My Add-in.
  4. Select the downloaded manifest.xml file.
  5. Enter =TESTVELIXO.FACTORIALROW(5) in a cell.

If the button does not save a file, open this page directly and try again, or use Right-click → Save link as… on manifest.xml.
